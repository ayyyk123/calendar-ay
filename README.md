# 나만의 캘린더 v1.13

주간 화면 중심의 개인 일정/업무량 관리 웹앱입니다.

## v1.13 변경사항
- 주간/월간 달력을 월요일부터 일요일 순서로 표시합니다.
- 반복 일정의 요일 선택도 월~일 순서로 표시합니다.
- 대한민국 공휴일 이름을 주간/월간/일간/목록 화면에 표시합니다.
- 공휴일과 일요일은 빨간색, 토요일은 파란색으로 구분합니다.
- 공휴일 데이터는 `hyunbinseo/holidays-kr`의 월력요항 기반 JSON을 온라인에서 불러오고 24시간 캐시합니다.
- 네트워크 오류 시에도 2026~2027 주요 공휴일 내장 데이터와 고정 공휴일을 사용해 표시가 완전히 사라지지 않도록 했습니다.
- v1.12의 Firebase 최신본 우선 로드, 저장 상태 표시, JSON 백업/복원, 이메일/비밀번호 로그인 및 업무량 관리 기능은 그대로 유지합니다.

## 백업
설정(⚙) → 데이터 백업 → `백업 다운로드`를 누르면 현재 전체 캘린더 데이터를 JSON 파일로 저장합니다.
백업 파일에는 캘린더/일정/고정업무/다이어리/설정 데이터만 포함되며 로그인 비밀번호는 포함되지 않습니다.

`백업 불러오기`를 누르면 현재 데이터를 해당 백업으로 덮어쓰며, Firebase 연결 상태라면 즉시 Firestore에도 저장합니다.

## Firebase 보안 규칙
Firestore Console → 규칙(Rules)에 `firestore.rules` 내용을 붙여넣고 게시하세요.
로그인한 사용자가 자신의 `users/{uid}/...` 데이터만 읽고 쓸 수 있도록 제한합니다.
