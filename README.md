# 캘린더 v1.22

v1.21의 모든 기능을 유지하면서 캘린더 목록 조작과 캘린더별 관련 항목 보기 기능을 개선했습니다.

## v1.22 변경사항
- 캘린더 목록에 `전체✓` / `전체해제` 버튼을 추가했습니다.
  - 전체✓: 모든 캘린더 표시
  - 전체해제: 모든 캘린더 숨김
- 캘린더 이름 클릭 동작을 수정했습니다.
  - 이제 이름을 클릭하면 해당 캘린더의 일정·할 일·습관·기념일을 목록 화면에서 확인합니다.
  - 상위 캘린더를 클릭하면 그 아래 부속캘린더 항목도 함께 표시합니다.
  - 날짜 지정 배치 업무도 같은 화면에서 함께 확인하고 수정할 수 있습니다.
- 캘린더 수정은 각 캘린더 오른쪽 `✎` 연필 버튼으로 분리했습니다.
- 캘린더별 관련 항목 보기 중인 캘린더는 왼쪽 목록에서 강조 표시됩니다.
- `전체 일정 보기` 버튼으로 필터를 해제할 수 있습니다.
- 기존 자동 저장, Firebase 동기화, 공휴일, 반복 일정, 고정업무, 이월 일정, 상·하위 캘린더 등은 그대로 유지됩니다.
