# 캘린더 v1.15

주간 화면 중심의 개인 일정/업무량 관리 웹앱입니다.

## v1.15 변경사항
- 새 부속캘린더에서 `상위 캘린더`를 선택하면 상위 캘린더와 같은 색 계열의 추천색을 자동 적용합니다.
- 하위 캘린더가 여러 개이면 같은 색상 계열을 유지하면서 밝기·채도를 조금씩 달리해 서로 구분합니다.
- 이미 만들어진 캘린더의 색상은 상위 캘린더를 바꿔도 임의로 덮어쓰지 않습니다. 필요할 때 `상위색 계열 추천` 버튼을 눌러 다시 추천받을 수 있습니다.
- 추천색이 마음에 들지 않으면 기존처럼 색상 선택창에서 자유롭게 수정할 수 있습니다.
- v1.14의 최신자료 저장, 부속캘린더, Firebase 자동동기화, 저장상태, 백업/복원, 공휴일, 월~일 배열, 상세 반복 일정 및 업무량 관리 기능을 모두 유지합니다.

## 데이터 저장
자동 저장과 별개로 상단 `최신자료 저장`을 누르면 현재 기기 데이터를 먼저 저장한 후 Firebase에 즉시 저장을 시도합니다. 상단 저장 상태에서 성공 시각을 확인할 수 있습니다.

## 백업
설정(⚙) → 데이터 백업 → `백업 다운로드`를 누르면 전체 캘린더 데이터를 JSON 파일로 저장합니다. `백업 불러오기`로 복원하면 현재 로그인 계정의 Firebase에도 같은 데이터가 저장됩니다.

## Firebase 보안 규칙
Firestore Console → 규칙(Rules)에 `firestore.rules` 내용을 붙여넣고 게시하세요. 로그인한 사용자가 자신의 `users/{uid}/...` 데이터만 읽고 쓸 수 있도록 제한합니다.
