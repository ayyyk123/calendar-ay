# 캘린더 v1.23

v1.22의 모든 기능을 유지하면서 PC 좌측바 사용성을 개선했습니다.

## v1.23 변경사항
- 좌측바와 달력 사이에 접기/펴기 버튼을 추가했습니다.
  - `‹` 버튼: 좌측바 접기
  - 접힌 상태의 `›` 버튼: 좌측바 다시 펴기
- PC에서 좌측바와 달력 사이 경계선을 마우스로 좌우 드래그해 너비를 조절할 수 있습니다.
  - 최소 210px, 최대 520px 범위
  - 경계선을 더블클릭하면 기본 너비 260px로 돌아갑니다.
- 좌측바 너비와 접힘 상태는 현재 기기에 저장되어 다음에 다시 열어도 유지됩니다.
  - PC와 휴대폰은 화면 크기가 다르므로 이 UI 설정은 Firebase 일정 데이터와 별개로 각 기기에 저장합니다.
- 모바일에서는 기존 햄버거 메뉴 방식이 그대로 유지됩니다.
- v1.22의 Firebase 동기화, 저장/백업, 캘린더 필터, 반복 일정, 고정업무, 공휴일 등 기존 기능은 그대로 유지됩니다.
