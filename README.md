# 캘린더 v1.44

## v1.44 변경사항
- 월간 화면은 해당 월에 실제로 필요한 4/5/6주만 표시합니다. 다음 달의 불필요한 한 주가 추가되어 월간 칸 높이가 짧아지는 문제를 수정했습니다.
- `날짜 지정 배치`와 `시간날때 업무`를 달력에 드래그해 넣으면 Quick이 아니라 일반 일정으로 등록됩니다.
- 캘린더 설정에서 월~일 요일별 가용시간을 각각 설정할 수 있습니다.
- 각 요일마다 `미정`을 개별 설정할 수 있고, 주간 업무량에는 확인된 가용시간과 미정 요일 수를 함께 표시합니다.
- 기존 데이터는 기존 하루 가용시간을 월~일 값으로 자동 이어받습니다.

기존 v1.43 기능(Firebase 동기화, 좌측 메뉴 순서, 빠른 일정 팝오버, D-Day/기념일 상단 표시 등)은 유지됩니다.
