# 캘린더 v1.21

v1.20의 모든 기능을 유지하면서 매월 반복 설정을 단순화했습니다.

## v1.21 변경사항
- 매월 반복의 `설정한 날짜`에서는 사용자가 고른 날짜에만 반복됩니다.
  - 예: 매월 31일로 설정하면 31일이 없는 달은 건너뜁니다.
- `매월 말일로 반복` 체크박스를 추가했습니다.
  - 체크: 시작 날짜와 관계없이 매월 마지막 날에 반복됩니다.
  - 체크 해제: 설정한 날짜에만 반복됩니다.
- 기존의 `몇째 주 같은 요일`, `마지막 같은 요일` 반복은 그대로 유지됩니다.
- 기존에 저장된 `매월 말일` 반복 일정도 그대로 호환됩니다.
- 자동 저장, 수동 최신자료 저장, Firebase 동기화, 백업/복원, 고정업무, 이월 일정, 상·하위 캘린더, 공휴일 등 기존 기능은 유지됩니다.
