# 캘린더 v1.36

Firebase + GitHub Pages용 개인 캘린더 웹앱입니다. 기존 v1.34 기능을 유지합니다.

## v1.36 변경사항
- 좌측 `자동반복` 업무를 현재 보고 있는 달의 발생 날짜 기준 오름차순으로 정렬
- `날짜 지정 배치` 업무는 이번 달 실제 배치 날짜 기준 오름차순 정렬, 미배치 업무는 뒤쪽 표시
- `납부일정`은 해당 월의 납부 날짜 기준 오름차순 정렬
- 일정/반복/납부/날짜지정/시간날때 업무에 `★ 중요` 표시 지원
- 달력 카드에서 `☆/★`를 눌러 중요도를 바로 전환 가능
- 긴 일정명은 줄바꿈 없이 한 줄 말줄임표로 표시하고, 마우스를 올리면 전체 제목을 툴팁으로 확인 가능

기존 Firebase 보안규칙은 그대로 사용하면 됩니다.


## v1.36 변경사항
- 캘린더 하루 가용시간을 `미정`으로 설정 가능하며, 미정이어도 이번 주 업무량에 표시됩니다.
- 달력 일정 카드 배경색을 캘린더 색상 계열로 표시합니다.
- 같은 날짜 안에서는 일정 카드를 드래그해 순서를 바꿀 수 있습니다. 반복 일정도 순서만 바꿀 때는 반복 설정이 유지됩니다.
- 일정에 세부 체크리스트를 등록할 수 있고 각 항목을 체크하면 전체 업무 완료가 자동 반영됩니다. 메모 줄을 체크리스트로 가져올 수도 있습니다.
