# 캘린더 v1.34

Firebase + GitHub Pages용 개인 캘린더 웹앱입니다. 기존 v1.33 기능을 유지합니다.

## v1.34 변경사항
- 좌측에 `시간날때 업무` 영역 추가: 고정/즉시 할 일이 아닌 업무를 등록하고 원하는 날짜로 반복 드래그 배치 가능
- 시간날때 업무를 달력에서 완료 체크하면 좌측 원본 업무에 완료한 날짜가 누적 기록
- 시간날때 업무와 납부일정 모두 캘린더별 그룹/필터 지원
- 납부일정에 `전체 캘린더 / 특정 캘린더` 필터 추가
- 월간 달력에서 일정이 많으면 일부만 표시하고 `+ N건` 버튼으로 해당 날짜 전체 목록 확인
- 날짜 지정 배치로 만든 일정은 일반/반복 일정과 구분되도록 제목 글자색을 별도 표시
- 월간 날짜 칸 높이를 고정해 일정이 많아도 셀 크기가 늘어나지 않도록 처리

기존 Firebase 보안규칙은 그대로 사용하면 됩니다.
