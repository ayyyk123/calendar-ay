# 캘린더 v1.30

- 반복 일정 삭제 시 `이 일정만 / 이후 일정 / 전체 반복 일정` 범위를 선택할 수 있습니다.
- 일반 일정과 반복 일정 모두 달력에서 마우스로 다른 날짜로 드래그할 수 있습니다. 반복 일정은 드래그한 발생일만 일회성 일정으로 분리되어 이동합니다.
- 시작/종료 시간을 모두 입력하면 예상 소요시간이 자동 계산되어 수동 입력이 비활성화됩니다.
- `납부일정` 유형과 좌측 전용 관리 영역을 추가했습니다. 금액/납부수단을 기록하고 날짜별 `☐/☑`로 납부완료를 체크할 수 있습니다.
- 납부일정은 업무 소요시간/업무량 계산에서 제외됩니다.
- 기존 Firebase 동기화, 백업/복원, 반복/고정업무, 부속캘린더, 공휴일, 이월 기능 등을 유지합니다.
