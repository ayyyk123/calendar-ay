# 캘린더 v1.19

주간 화면 중심의 개인 일정·업무량 관리 웹앱입니다.

## v1.19 변경사항
- 왼쪽 `매월 고정업무`의 `＋` 버튼을 누르면 추가 방식을 먼저 선택합니다.
  - `매월 자동반복 업무 추가`: 일정 등록창을 매월 반복·할 일·종일 일정으로 미리 설정해서 열며, 매월 반복 상세 규칙을 바로 지정할 수 있습니다.
  - `날짜 지정 배치 추가`: 드래그 배치용 고정업무 등록창을 엽니다.
- 날짜 지정 배치 등록창 제목도 `날짜 지정 배치 업무 추가/수정`으로 명확하게 표시합니다.
- v1.18의 Firebase 동기화, 최신자료 저장, 백업/복원, 월~일 배열, 대한민국 공휴일, 상·하위 캘린더, 색상 추천, 상세 반복, 고정업무 배치완료 잠금/배치일 표시, 미완료 일정 이월 기능을 모두 유지합니다.
