# 캘린더 v1.27

## v1.27 변경사항
- 주/월/일/목록 달력의 업무 카드에 완료 버튼을 더 눈에 띄게 표시합니다. `☐ 완료`를 누르면 완료, 다시 누르면 완료 취소됩니다. 월간 화면에서는 공간 때문에 체크 아이콘만 표시됩니다.
- 반복 업무는 달력에서 제목 글자색을 보라 계열로 구분해 일반/일회성 업무와 한눈에 구별됩니다.
- 반복 업무의 각 발생일 완료 상태는 서로 독립적으로 저장됩니다.
- 왼쪽 `자동반복` 목록에 현재 보고 있는 달 기준 `이번 달 n/m 완료` 또는 `✓ 이번 달 완료`가 표시됩니다.
- 왼쪽 `날짜 지정 배치` 목록에도 배치 후 `이번 달 미완료`/`✓ 이번 달 완료` 상태가 표시됩니다.
- 날짜 지정 배치 업무는 기존처럼 배치 후 비활성화되며, 달력에서 해당 업무를 완료 체크하면 왼쪽 완료 상태도 즉시 갱신됩니다.

기존 v1.26 기능은 모두 유지합니다.
