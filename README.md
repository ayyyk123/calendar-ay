# 캘린더 v1.47

## v1.47 변경사항
- 모바일 화면을 3단 헤더(저장상태 / 보기버튼 / 날짜이동)로 재배치해 버튼과 날짜범위 겹침을 제거했습니다.
- 모바일 주간에서도 월~일 7개 열은 한 화면에 유지하면서 일정 카드·그룹·날짜헤더를 압축했습니다.
- 모바일 날짜 범위는 `9/28–10/4`처럼 짧게 표시하고 전체 범위는 툴팁으로 유지합니다.
- iPhone Safari에서 오늘 버튼·날짜 입력·보기 버튼이 줄바꿈되거나 커지는 문제를 보정했습니다.

- 반복 일정을 다른 날짜로 드래그할 때 이동 범위를 선택하도록 추가했습니다.
- `이 일정만 이동`: 선택한 발생일만 일회성 일정으로 옮기고 이후 반복 패턴은 그대로 유지합니다.
- `이 일정부터 이후 반복일정 이동`: 옮긴 날짜를 새 기준일로 삼아 이후 반복일정을 다시 이어갑니다. 예: 2일마다 헬스장 9/27→9/29→10/1 중 9/27을 9/28로 옮기면 이후가 9/28→9/30→10/2로 이어집니다.
- `전체 반복일정 기준 변경`: 반복 시리즈 전체를 같은 날짜 차이만큼 이동합니다.
- 가용시간 차단 반복일정도 같은 이동 규칙을 사용하므로, `이 일정부터 이후 반복일정 이동`을 선택하면 원래 날짜의 가용시간은 복구되고 새 반복 날짜들만 0h 차단됩니다.
- 날짜 이동은 반복 설정을 해제하지 않으며, 반복 간격과 종료 조건을 가능한 범위에서 유지합니다.

기존 v1.45 기능과 데이터는 그대로 이어집니다.
