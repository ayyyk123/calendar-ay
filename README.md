# 캘린더 v1.42

## v1.40 변경사항

- 달력 일정 카드를 기본 한 줄형으로 정리했습니다. 완료 체크는 네이버 캘린더처럼 작은 체크박스를 한 번 눌러 완료/해제합니다.
- 소요시간은 제목 맨 앞에 `(1h) 매출입력`, `(0.5h) 거래처 확인`처럼 표시합니다.
- 체크리스트가 있는 일정은 기본 한 줄을 유지하고 `☷ n/m` 버튼을 눌렀을 때만 세부 체크리스트가 펼쳐집니다. 메인 체크박스를 누르면 체크리스트 전체를 한 번에 완료/해제할 수 있습니다.
- 주간/일간의 날짜 칸 안에서 캘린더 그룹별로 접기/펴기를 할 수 있습니다. 접힘 상태는 날짜+캘린더별로 저장됩니다.
- 기존 반복 일정 순서 변경 범위 선택, Firebase 동기화, Quick, 납부일정, 고정/시간날때 업무 등 기존 기능은 유지합니다.
- 일정이 많아 화면 높이를 넘으면 달력 본문이 정상적으로 세로 스크롤됩니다.

## v1.38 변경사항

- 같은 날짜 안에서 반복 일정을 드래그해 순서를 바꾸면 적용 범위를 선택합니다.
  - `이 날짜만 적용`: 그 날짜에서만 순서를 바꿉니다.
  - `반복 일정 전체에 적용`: 같은 캘린더의 다른 반복 날짜에도 해당 순서를 기본 순서로 적용합니다.
- 순서 변경은 반복 설정 자체를 해제하거나 일회성 일정으로 분리하지 않습니다.
- 기존 날짜별로 따로 지정한 순서가 있는 날짜는 그 날짜의 개별 순서를 우선 유지합니다.


Firebase + GitHub Pages용 개인 캘린더 웹앱입니다. 기존 v1.34 기능을 유지합니다.

## v1.37 변경사항
- 좌측 `자동반복` 업무를 현재 보고 있는 달의 발생 날짜 기준 오름차순으로 정렬
- `날짜 지정 배치` 업무는 이번 달 실제 배치 날짜 기준 오름차순 정렬, 미배치 업무는 뒤쪽 표시
- `납부일정`은 해당 월의 납부 날짜 기준 오름차순 정렬
- 일정/반복/납부/날짜지정/시간날때 업무에 `★ 중요` 표시 지원
- 달력 카드에서 `☆/★`를 눌러 중요도를 바로 전환 가능
- 긴 일정명은 줄바꿈 없이 한 줄 말줄임표로 표시하고, 마우스를 올리면 전체 제목을 툴팁으로 확인 가능

기존 Firebase 보안규칙은 그대로 사용하면 됩니다.
