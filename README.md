# 캘린더 v1.14

주간 화면 중심의 개인 일정/업무량 관리 웹앱입니다.

## v1.14 변경사항
- 상단에 `최신자료 저장` 버튼을 추가했습니다. 자동 저장은 그대로 유지하면서, 원할 때 현재 데이터를 즉시 Firebase에 저장할 수 있습니다.
- 앱 표시 이름을 `나만의 캘린더`에서 `캘린더`로 변경했습니다.
- 기존 캘린더 아래에 부속캘린더를 만들 수 있습니다. 예: `개인업무 › 결혼준비`, `개인업무 › 웨딩카페할일`.
- 캘린더 설정에서 `상위 캘린더`를 선택하면 부속캘린더가 됩니다. 단계형 부속캘린더도 지원합니다.
- 사이드바, 일정/고정업무 선택창, 고정업무 목록에서 부속캘린더를 들여쓰기/경로로 구분합니다.
- 주간/일간 화면에서는 상위 캘린더 안에 부속캘린더 일정이 묶여 보이며, 상위 캘린더 총 소요시간과 부속캘린더별 소요시간을 함께 확인할 수 있습니다.
- 상위 캘린더 숨김 시 하위 부속캘린더도 함께 숨겨집니다.
- 상위 캘린더 삭제 시 부속캘린더 자체는 삭제하지 않고 한 단계 위로 이동해 유지합니다.
- v1.13의 월~일 배열, 대한민국 공휴일, Firebase 최신본 우선 로드, 저장 상태 표시, JSON 백업/복원, 이메일/비밀번호 로그인, 반복 일정과 업무량 관리 기능을 유지합니다.

## 데이터 저장
자동 저장과 별개로 상단 `최신자료 저장`을 누르면 현재 기기 데이터를 먼저 저장한 후 Firebase에 즉시 저장을 시도합니다. 상단 저장 상태에서 성공 시각을 확인할 수 있습니다.

## 백업
설정(⚙) → 데이터 백업 → `백업 다운로드`를 누르면 전체 캘린더 데이터를 JSON 파일로 저장합니다. `백업 불러오기`로 복원하면 현재 로그인 계정의 Firebase에도 같은 데이터가 저장됩니다.

## Firebase 보안 규칙
Firestore Console → 규칙(Rules)에 `firestore.rules` 내용을 붙여넣고 게시하세요. 로그인한 사용자가 자신의 `users/{uid}/...` 데이터만 읽고 쓸 수 있도록 제한합니다.
