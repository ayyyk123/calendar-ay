# 캘린더 v1.25

## v1.25 변경사항
- 캘린더 이름 클릭 시 주/월/일/목록 보기 상태를 변경하지 않고 현재 화면에서 해당 캘린더만 필터링합니다.
- 상위 캘린더 이름 클릭은 상위+부속캘린더, 부속캘린더 이름 클릭은 해당 부속캘린더만 표시합니다.
- 캘린더 체크박스를 각 캘린더별 독립 표시/숨김으로 수정해 부속캘린더 체크가 항상 개별 동작합니다.
- GitHub Pages/브라우저 캐시 때문에 이전 app.js가 남는 문제를 막기 위해 CSS/JS/manifest에 v1.25 캐시 버스터를 추가했습니다.


Firebase + GitHub Pages 기반 개인 캘린더 웹앱입니다.

## v1.25 변경사항
- 캘린더 이름을 눌러도 `목록` 화면으로 강제 이동하지 않습니다.
- 주/월/일/목록 중 현재 보고 있던 화면을 그대로 유지하면서 선택한 캘린더 내용만 필터링합니다.
- 상위 캘린더를 누르면 해당 상위 + 부속캘린더 일정만 표시합니다.
- 부속캘린더를 누르면 해당 부속캘린더(및 그 아래 하위가 있으면 하위) 일정만 표시합니다.
- 같은 캘린더 이름을 한 번 더 누르면 `전체 보기`로 돌아옵니다.
- 선택 중인 캘린더는 왼쪽 목록에서 강조되고 상단 날짜 범위에 `~만 보기`가 표시됩니다.
- 캘린더 체크박스 표시/숨김이 주/월/일/목록 화면에 즉시 반영됩니다.
- 상위 캘린더 체크 해제 시 하위도 함께 해제되지만, 이후 원하는 부속캘린더만 다시 개별 체크하여 표시할 수 있습니다.
- `전체✓ / 전체해제` 동작도 메인 달력 표시와 즉시 연동됩니다.

## 기존 주요 기능
- 이메일/비밀번호 Firebase Authentication
- 사용자별 Firestore 실시간 동기화 및 수동 `최신자료 저장`
- JSON 백업 다운로드/복원
- 주/월/일/목록 보기, 대한민국 공휴일
- 캘린더/부속캘린더, 우선순위·가용시간·업무량 계산
- 매월 자동반복/날짜 지정 배치, 고정업무 드래그 배치
- 상세 반복 설정, 소요시간 미체크, 다음날 이월
- 좌측바 접기/펴기 및 너비 조절
