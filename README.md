# 캘린더 v1.26

## v1.26 변경사항
- 왼쪽 `매월 고정업무` 영역을 `반복 / 고정업무`로 변경했습니다.
- `＋ > 자동반복 업무 추가`에서 반복 종류를 직접 `매일 / 매주 / 매월 / 매년`으로 선택할 수 있습니다. 반복 선택은 더 이상 `매월`로 잠기지 않습니다.
- 자동반복 업무 추가창은 기본값을 `매주`로 열며, 시작 날짜의 요일이 자동 선택됩니다. 예: 시작일이 월요일이면 `매주 월요일`이 기본값입니다.
- 자동반복 목록은 매월 반복뿐 아니라 매일/매주/매월/매년 반복 업무를 모두 표시합니다.
- 왼쪽 자동반복 목록에 `매주 월요일`, `2주마다 월·목요일`, `매월 말일`, `매년 11월 8일`처럼 실제 반복 규칙이 표시됩니다.
- `날짜 지정 배치 추가`와 기존 드래그 배치 기능은 그대로 유지합니다.

## 기존 주요 기능
- 이메일/비밀번호 Firebase Authentication 및 사용자별 Firestore 동기화
- 수동 `최신자료 저장`, 최근 저장 시각, JSON 백업/복원
- 주/월/일/목록 보기, 대한민국 공휴일
- 상위/부속캘린더, 캘린더 필터 및 개별 표시/숨김
- 예상 소요시간/소요시간 미체크, 캘린더별 업무량 계산
- 날짜 지정 업무 드래그 배치, 배치 완료/날짜 표시
- 다음날 이월 및 이월 누적 표시
- 좌측바 접기/펴기 및 너비 조절
