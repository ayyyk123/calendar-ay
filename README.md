# 캘린더 v1.43

Firebase + GitHub Pages용 개인 캘린더 웹앱입니다.

## v1.43 변경사항
- 달력의 일정 카드를 한 번 클릭하면 전체 수정창 대신 작은 빠른보기 팝오버가 열립니다.
- 빠른보기 팝오버에서 `완료 / 납부완료`를 바로 체크할 수 있고, `✎ 수정`을 눌렀을 때만 전체 수정창이 열립니다.
- `D-Day / 기념일`은 `예약 · 약속`처럼 날짜 상단 전용 영역에 표시되며 일반 캘린더 묶음 안에는 들어가지 않습니다.
- 월간 화면에서도 D-Day/기념일과 예약·약속이 일반 일정보다 먼저 보이도록 우선순위를 적용했습니다.
- 좌측 메뉴의 `⋮⋮` 손잡이를 드래그해 캘린더 / 반복·고정업무 / 시간날때 업무 / 구매목록 / 납부일정 / 이번 주 업무량 / D-Day·기념일 순서를 직접 바꿀 수 있습니다.
- 좌측 메뉴 순서는 Firebase에 저장되어 같은 계정에서 유지됩니다.

## 기존 주요 기능
- 주 / 2주 / 3주 / 월 / 일 / 목록 보기
- Firebase 이메일/비밀번호 로그인 및 자동 동기화
- 자동반복 / 날짜지정 배치 / 시간날때 업무 / 구매목록 / 납부일정
- 음력 생일 및 음력 매년 반복
- 캘린더/부속캘린더, 가용시간, 업무량 계산
- 일정 드래그 이동 및 같은 날짜 내 순서 변경
- 반복 일정 삭제 범위 선택
- 체크리스트, 다음날 이월, 중요도, 백업/복원
