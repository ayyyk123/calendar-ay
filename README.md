# 나만의 캘린더 v1.12

주간 화면 중심의 개인 일정/업무량 관리 웹앱입니다.

## v1.12 변경사항
- Firebase 최신본 우선 로드: 로그인 직후 온라인 상태에서는 Firestore 서버의 최신 데이터를 먼저 불러옵니다.
- 같은 이메일/비밀번호 계정으로 로그인하면 PC/모바일에서 같은 Firebase 데이터를 사용합니다.
- 상단에 저장 상태 표시: `저장 대기 → 저장 중 → Firebase 저장완료 시각 → 저장 실패`를 확인할 수 있습니다.
- 설정에서 최근 Firebase 저장 시각과 최근 기기 저장 시각을 각각 확인할 수 있습니다.
- 데이터 백업 다운로드(JSON) 추가.
- 백업 불러오기/복원 추가. 복원하면 현재 로그인 계정의 Firebase 데이터도 같은 내용으로 저장합니다.
- 로그인 직후 Firebase 최신 데이터를 확인하는 동안 로딩 화면을 표시해 오래된 기기 저장본을 먼저 수정하는 일을 방지합니다.
- v1.11의 이메일/비밀번호 로그인, 반복 일정 상세설정, 주간 화면 중심 UI, 고정업무, 업무량 계산 기능은 그대로 유지합니다.

## 백업
설정(⚙) → 데이터 백업 → `백업 다운로드`를 누르면 현재 전체 캘린더 데이터를 JSON 파일로 저장합니다.
백업 파일에는 캘린더/일정/고정업무/다이어리/설정 데이터만 포함되며 로그인 비밀번호는 포함되지 않습니다.

`백업 불러오기`를 누르면 현재 데이터를 해당 백업으로 덮어쓰며, Firebase 연결 상태라면 즉시 Firestore에도 저장합니다.

## Firebase 보안 규칙
Firestore Console → 규칙(Rules)에 `firestore.rules` 내용을 붙여넣고 게시하세요.
로그인한 사용자가 자신의 `users/{uid}/...` 데이터만 읽고 쓸 수 있도록 제한합니다.
